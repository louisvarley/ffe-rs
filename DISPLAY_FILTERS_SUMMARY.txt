DECISION
================================================================================

✅ YES - Add CRT scanline overlay effect
⏸️ DEFER - GPU-based CRT shaders (requires architecture change)
❌ NO - Modern 3D filtering techniques (not applicable to software renderer)

================================================================================
WHY THIS MAKES SENSE
================================================================================

FFE-RS-Classic uses PURE SOFTWARE RENDERING:
• Game renders to 320×200 indexed-color framebuffer (CPU)
• Palette lookup produces 320×200 RGBA
• This frame is scaled to modern display resolution
• No GPU 3D rendering, no perspective textures

This architecture is PERFECT for pixel-art upscaling algorithms:
• Filters operate on small 320×200 input (fixed cost regardless of output size)
• CPU-based processing fits the existing pipeline
• No shader support needed from minifb library
• Retro gaming community has proven these filters work excellently

================================================================================
RECOMMENDED FILTERS
================================================================================

PRIMARY: xBRZ 2x/3x
  • Edge-aware upscaling that smooths pixel art intelligently
  • Preserves sharp edges, smooths curves and diagonals
  • ~5-12ms processing time (acceptable for 60 FPS)
  • Used successfully in DOSBox, RetroArch, many emulators
  • BEST for modern 1080p/1440p/4K displays

ALTERNATIVE: Scale2x
  • Simple edge-directed scaling
  • <1ms processing time (very fast)
  • Subtle enhancement, mostly sharp
  • BEST for low-end systems

OVERLAY: CRT Scanlines
  • Horizontal dark lines simulating CRT display
  • Negligible performance cost
  • Configurable intensity (0-100%)
  • Combines with any base filter

KEEP EXISTING: Nearest Neighbor (Default), Linear/Bilinear

================================================================================
WHAT NOT TO ADD (Does Not Apply to Software Renderer)
================================================================================

❌ Anisotropic filtering (for 3D perspective textures - game uses affine CPU mapping)
❌ MSAA/SSAA (for GPU geometry anti-aliasing)
❌ FXAA/SMAA (for GPU rendering artifacts)
❌ TAA (requires motion vectors from GPU pipeline)

The user asked about "texture filtering" and "pixel scaling" as separate options,
but in FFE-RS-Classic there is NO DISTINCTION - everything is rasterized to a
single 320×200 2D framebuffer before filtering. One filter applies to everything.

PERFORMANCE
================================================================================

Target: 60 FPS (16.67ms frame time)

  Component               Time
  ─────────────────────  ──────
  Game rendering         8-12ms
  xBRZ 2x filter         ~5ms   ✅
  Scale2x filter         <1ms   ✅
  Scanlines              <0.1ms ✅
  Presentation           1-2ms
  ─────────────────────  ──────
  TOTAL                  14-20ms

xBRZ 3x (~12ms) is borderline - may need optimization or performance warning.

Performance:
