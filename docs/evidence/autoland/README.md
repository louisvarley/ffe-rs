# Starport auto-landing frames

Generated by `cargo test -p ffe-rs --test navigation -- --ignored` with
`FFE_WORLD_CACHE` pointing at a v29 cache built from this branch and
`FFE_SHOT_DIR` set, then converted from the port's 320x200 PPM frames to PNG.
The default new game (Gateway, Hope, Old Blackelk, model 0x56) is the target.

| Frame | Test | Shows |
|---|---|---|
| `autoland-0000-approach.png` | `starport_autopilot_lands_on_the_pad` | the ship at F741's 6,144,000 mm approach above the open-air port, Hope below and the port's buildings to the right |
| `autoland-9999-pad.png` | `starport_autopilot_lands_on_the_pad` | the open-air pad's `0x30` view from F650's seat (the starport's buildings around the cockpit) after F746/F744/F652's touch and F1048 |
| `manual-0000-above.png` | `manual_pad_contact_reaches_0x30` | the F994 three-body frame at the pad before the F569/F576 scan |
| `manual-9999-pad.png` | `manual_pad_contact_reaches_0x30` | the same view after F1019's `0x2e` and F1048's `0x30` |

The source map and the F576 model-data fix are in
[`docs/notes/autoland.md`](../../notes/autoland.md).
