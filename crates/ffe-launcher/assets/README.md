# Launcher artwork

`background.jpg` is the approved launcher mockup (concept artwork supplied by
the project owner, `elite3_launcher_assets_v2`) with its baked-in sidebar
labels, file rows, launch button, footer text and window buttons removed, so
the launcher draws those as live UI in the same places. It is concept art,
not original game content.

The mockup's SVG icons, panel border and launch button are redrawn in
`src/draw.rs` from their paths; the palette is the pack's `theme.json`.
